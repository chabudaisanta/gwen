title: 円と円の交点 (Circle)

中心と半径で表す円周、および円周同士の交点を扱います。名前空間は `gwen::geo`、座標と半径の型 `T` は `std::floating_point` を満たす型です。通常は `f64` または `f80` を使用します。

## **Circle(center, radius)**

```cpp
Circle<T> circle(Point<T> center, T radius);
```

公開メンバ `center`、`radius` に中心と半径を保持します。半径0の円周は中心1点です。

**制約**
- 中心の座標と半径は有限、`radius >= 0`。
- 構築後にメンバを変更した場合も同じ制約を満たす必要があります。構築時と交点計算時に `assert` で検査します。

**計算量**
- $O(1)$

## **intersection(c1, c2, eps)**

```cpp
template <std::floating_point T>
std::pair<i32, std::array<Point<T>, 2>>
intersection(const Circle<T>& c1, const Circle<T>& c2, T eps = T(1e-10));
```

交点数と最大2点の配列を返します。

| `first` | 意味 | `second` の有効要素 |
| --- | --- | --- |
| `0` | 交点なし | なし |
| `1` | 接点、点円の交点、または許容誤差内の近似接点 | `[0]` のみ |
| `2` | 2交点 | `[0]` と `[1]` |
| `-1` | 同一の正半径円で交点が無限個 | なし |

2交点は `CompareXy` による辞書式順（x座標、次いでy座標）で返します。ソートには許容誤差を用いません。

```cpp
using namespace gwen;
using namespace gwen::geo;
const Circle<f64> a({0, 0}, 2), b({2, 0}, 2);
const auto [count, points] = intersection(a, b);
// count == 2、points は (1, -sqrt(3)), (1, sqrt(3))
```

### 誤差と退化ケース

- 同中心・同半径は厳密比較します。同じ正半径なら `-1`、同じ半径0なら `1`。同中心・異半径は `eps` に関係なく `0` です。
- 異中心で半径0を含む場合、点円の中心から相手円周までの距離が `eps` 以下なら、その中心を1点返します。
- 正半径・異中心では、中心間距離を $d$、半径和を $s$、半径差の絶対値を $\delta$ とします。$\delta < d < s$ は2点、$d = \delta$ または $d = s$ は1点です。真の2交点を `eps` で1点にまとめません。
- 厳密には交わらない異中心円でも、円周間隔が `eps` 以下なら、最寄り円周点同士の中点を近似接点として返します。丸め誤差を除く数学的な各円周への残差は円周間隔の半分以下です。
- `eps` は座標と同じ単位の絶対許容誤差です。`eps = 0` で近似接点の緩和を無効にできますが、丸め誤差は残ります。真の交点数の判定も浮動小数点で計算した $d, s, \delta$ に依存します。

**制約**
- 全座標、半径、`eps` は有限、半径と `eps` は非負。
- 座標差、半径和、積、商等の中間演算が `T` で表現でき、非零の除数が丸めで0にならない必要があります。
- 接点近傍や桁落ちの強い入力では精度が低下します。`f32`・大きい座標・極端なスケールでは型と `eps` を入力に合わせて指定してください。

**計算量**
- 時間・補助空間ともに $O(1)$。動的な配列確保は行いません。
